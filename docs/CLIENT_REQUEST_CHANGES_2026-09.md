# Client request features — Voice of Clients platform

**Product:** RSM in Kuwait Voice of Clients (Nexuses)  
**Date:** 2026-09-21

Feature-by-feature status for items requested by Nexuses and the RSM team.

---

## From Nexuses

### 1. 2FA authentication
**Status: Done**

Dashboard sign-in requires email + password, then a 6-digit email OTP (MFA) on every login.

---

### 2. Change dashboard colour
**Status: Partially done**

CSAT, CES, and NPS use the agreed brand identity colours and metric logos on the dashboard and report pages. Some icons are still pending.

---

### 3. Reset password option for admins
**Status: Done**

Settings → **Account** lets Settings users (including admins) change their own password: current password, new password, and confirm. Password fields include show/hide.

---

### 4. Report update
**Status: Partially done**

CSAT / NPS / CES report pages updated (layout, filters, branding). Further report changes can follow if needed.

---

### 5. Share access with clients
**Status: Done**

Clients can be given public, PII-free links:
- Experience report: `/reports`
- Metrics widget: `/widget`
- Reviews widget: `/widget/reviews`

---

### 6. Same email — keep latest scores (quarterly)
**Status: Done**

If the same email completes more than one survey in the same UTC calendar quarter, only the **most recent** scores count in KPIs and the Responses view. Earlier submissions for that email/quarter are soft-excluded.

---

### 7. Edit of survey options for Admin and Noha (exclude / delete)
**Status: Done**

Users with response-manage permission (e.g. Admin, Noha) can **Exclude** or **Delete** a survey response from the Responses ledger.

---

### 8. Export option for Invite tracker — Excel
**Status: Done**

Invite tracker supports Excel (and CSV) export of outreach records.

---

### 9. Connect invite tracker to chat
**Status: Done**

Insights chat can answer invite outreach questions (totals and status) and, for a given email/client, linked survey feedback when available.

---

### 10. Survey auditor — send survey, not edit
**Status: Done**

**Surveyor** role can send surveys and use the invite tracker. It cannot exclude/delete responses or manage users/roles.

---

### 11. Negative survey notified to Admins and CX
**Status: Done**

On completion, Admins/CX receive notification email. Low scores (CSAT ≤ 2, CES ≤ 3, or NPS ≤ 6) trigger a needs-attention / action-required notification.

---

### 12. Public link for widget
**Status: Done**

Public widget pages and embeddable scripts are available (`/widget`, `/widget/reviews`).

---

### 13. Give Shivali and Sharon access for received surveys
**Status: Done**

Access provisioned so Shivali and Sharon can view received surveys as agreed.
